# PharmaZone 💊
### The Ultra-Premium B2B & B2C Healthcare Ecosystem

PharmaZone is a high-fidelity, comprehensive healthcare platform designed to bridge the gap between Patients, Pharma Vendors, and Medical Professionals. Built with a focus on **Apple-style aesthetics**, **AI-driven insights**, and **secure multi-role workflows**, PharmaZone is the future of digital pharmacy.

## 🚀 Key Features

### 🏢 Multi-Role Administrative Hub
*   **Super Admin & Sub-Admin Control**: Secure registration with Authority Secret Keys.
*   **Granular Permissions**: Manage Users, Vendors, Doctors, and Analytics from a centralized command center.
*   **Real-time Analytics**: 3-year growth timelines (2024-2026) with interactive BAR charts and sales performance tracking.

### 🏬 Pharma Vendor Portal
*   **Inventory Management**: Track stock levels, add medicines, and receive low-stock alerts.
*   **OCR Prescription Scanner**: Integrated AI engine to extract doctor details and medicine data from uploaded prescriptions.
*   **GST Billing**: Generate professional, GST-compliant invoices with PDF download capabilities.
*   **Vendor-Patient Chat**: Multi-channel communication system for seamless order fulfillment.

### 👨‍⚕️ Digital Doctor Clinic
*   **Professional Onboarding**: Specialized signup for doctors with Medical License verification.
*   **Online Consultation**: Dedicated flow for doctors to review patient symptoms and issue digital prescriptions.

### 🛒 Patient & Consumer Experience
*   **Price Comparison Engine**: Real-time price scanning across platforms like Tata 1mg, Apollo, and PharmEasy.
*   **Generic Substitute System**: Automatically suggests cheaper "Generic" alternatives based on salt composition—**Save up to 60%**.
*   **Secure Checkout**: Supports Prescription verification or Online Consultation modes.

## 🏗️ Getting Started

### Prerequisites
*   Node.js (v18+)
*   npm or yarn

### Installation
1.  **Clone the Repository**
    ```bash
    git clone https://github.com/your-username/PharmaZone.git
    cd pharmazone
    ```
2.  **Install Dependencies**
    ```bash
    npm install
    ```
3.  **Run Development Server**
    ```bash
    npm run dev
    ```

## 🛡️ Security
PharmaZone implements strict security layers:
*   **Secret Key Verification**: Admins cannot sign up without the specialized Authority Key.
*   **Rx Validation**: Mandatory prescription flows for restricted medicines.
*   **Role-Based Access Control (RBAC)**: Ensuring users only see the features intended for them.
